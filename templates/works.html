DESKTOP APPLICATION

Assignment Tracker

A Python desktop app made with classmates to help students keep track of assignments and deadlines.

The application includes assignment entry, a calendar view, upcoming deadlines, status updates, and reminder logic. Its interface is built with Tkinter and its data layer uses MySQL.
